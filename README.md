# 📊 Customer Analytics com SQL | Análise de Clientes e Fidelização

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de aplicar SQL na resolução de problemas reais de negócio relacionados ao comportamento dos clientes.

Utilizando uma base pública de transações de um e-commerce internacional com mais de **540 mil registros**, foram realizadas análises exploratórias e consultas SQL para identificar padrões de compra, segmentar clientes e gerar informações estratégicas para apoiar decisões comerciais.

Mais do que escrever consultas SQL, o foco deste projeto foi compreender como transformar dados em informações relevantes para o negócio.

---

## 🎯 Objetivos

Responder perguntas de negócio como:

- Quem são os clientes mais frequentes?
- Quem gera maior receita?
- Clientes que compram mais são os que mais gastam?
- Qual o ticket médio dos clientes?
- Quais clientes estão inativos?
- Quais países concentram mais clientes e faturamento?
- Quais produtos possuem maior saída?
- Como segmentar clientes para programas de fidelização?
- Quais clientes possuem maior potencial de crescimento?

---

## 📂 Base de Dados

Base pública: **Online Retail II**

A base contém aproximadamente **541 mil registros** de vendas realizadas entre 2010 e 2011.

Principais campos utilizados:

- Invoice
- CustomerID
- StockCode
- Description
- Quantity
- InvoiceDate
- UnitPrice
- Country

---

## 🔍 Etapas do Projeto

Antes das análises de negócio foi realizada uma **Análise Exploratória dos Dados (EDA)** para avaliar a qualidade da base.

Foram respondidas perguntas como:

- Quantidade de registros
- Clientes únicos
- Produtos únicos
- Países presentes
- Primeira e última compra
- Valores nulos
- Quantidades negativas (devoluções)
- Produtos com preço zero
- Faturamento bruto

Após essa etapa foram desenvolvidas **12 análises de negócio**, abordando comportamento dos clientes, faturamento, segmentação e indicadores estratégicos.
